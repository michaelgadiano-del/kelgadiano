# WEBDEV3 Week 10 Activities

The activities are separate Laravel applications so their routes, databases, and files stay isolated:

- `lab-exercise-8` — course catalogue with Breeze, roles, a course policy, and ownership rules.
- `library-accounts` — library catalogue, member loans, librarian desk, and admin role management.

Each folder has its own `composer.json`, `.env`, routes, migrations, and tests. Configure the MySQL
database named in that project's README before running its migrations.
